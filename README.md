# hotel-management-system
# Description
A Python-based Hotel Management System designed to simplify hotel operations. The system enables customer registration, room booking with different room types, check-in and check-out management, food ordering, automatic bill generation, room availability tracking, and customer record management. It also includes an Admin Control Menu for efficient hotel administration.

# Features
- Customer Registration
- Room Booking
- Room Type Selection (Standard, Deluxe, Suite)
- Check-In and Check-Out
- Food Ordering System
- Automatic Bill Generation
- Room Availability Tracking
- Customer Record Management
- Search and Update Customer Details
- Admin Control Menu

# Technologies Used
- Python

# How to Run
1. Download or clone the repository.
2. Open the project in Python IDLE, VS Code, or any Python IDE.
3. Run the `hotel_management.py` file.
4. Use the menu options to manage hotel operations.
